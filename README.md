# Fidelidade à Escritura

Traduções fiéis de clássicos da filosofia e história para o português brasileiro.

## Sobre

Este projeto oferece traduções de obras em **domínio público**, feitas a partir dos
textos originais (grego, latim, etc.) com auxílio de IA e revisão manual.

O objetivo é suprir a carência de traduções acessíveis e fiéis em PT-BR.

## Como funciona

- O texto original (domínio público) é traduzido com auxílio de IA
- A tradução é revisada manualmente
- O resultado é publicado como PDF neste repositório

## Categorias

- **Filosofia** — Platão, Aristóteles, etc.
- **História** — Tucídides, Heródoto, etc.

## Como contribuir

Se quiser contribuir com uma tradução, revisão ou sugestão de obra, abra uma issue.

## Licença

Todas as obras traduzidas estão em domínio público. As traduções deste projeto
são livres para uso, desde que citada a fonte.
